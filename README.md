# FIGO Gynecologic Cancer Staging Calculators

Combined offline-capable web app with calculators for:

- Cervical cancer
- Endometrial cancer
- Epithelial ovarian, fallopian tube, and peritoneal cancer
- Gestational trophoblastic neoplasia
- Uterine leiomyosarcoma
- Vaginal cancer
- Vulvar cancer

Open `start.html` to choose a calculator. The file `index.html` is also kept because websites such as GitHub Pages open it automatically.

For iPhone, iPad, Android, and tablets, host this folder from an HTTPS website such as GitHub Pages, open the HTTPS link once, then add it to the Home Screen.

## Removing the app from a device

The installed web app is easy to delete.

- iPhone/iPad: long-press the Home Screen icon, then choose Remove Bookmark or Delete Bookmark.
- Android: long-press the Home Screen icon, then choose Remove or Uninstall.
- Laptop/desktop: delete the downloaded folder or remove the browser shortcut/bookmark.

Deleting the icon or folder removes local access to the app. The web version can be opened again from the official link if needed.

## Update notifications

Email registration for update notifications should be voluntary. Users may be invited to deposit an email address through the official FIGO website for annual update notices. The offline calculator itself should not collect or store email addresses or personal information.

These calculators are staging aids only. Confirm final FIGO stage with complete clinical, imaging, operative, pathological, and multidisciplinary information before clinical use.
